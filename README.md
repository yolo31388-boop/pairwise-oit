# pairwise-oit

半透明特效叠在一起时，顺序一换颜色就变：加权混合的权重只用了 alpha，没有按深度和颜色亮度归一；深度剥离每层都重新走一遍几何，层数一多就掉帧；per-pixel linked list 的节点池满了直接丢弃新片段，烟雾出现空洞；MSAA 下每个采样点共用一份链表头，边缘出现条纹；透明粒子排序按对象中心，长条形激光和烟雾互相穿插；OIT 解析阶段没有做 gamma 校正，叠加后发灰。render/oit.py 是核心，tests/test_oit.py 15个红。要修的是：权重按深度/亮度归一；深度剥离复用几何；链表池满做淘汰；MSAA 按采样点建链表；按像素深度排序；解析阶段在线性空间合成。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
